# Quilt UI/UX 设计规范

> 版本 v2 · 2026-09-10。本文是 Quilt 全部界面的唯一设计事实源。
> 关键词：布片与格子。格子是唯一的视觉主角，其余一切让路。
> v2 新增：弹性节奏（每周 N 次）的语义与展示、提醒静默、可配置格子组件。

## 0. 设计 token（Theme.swift）

| Token | 值 | 用途 |
|---|---|---|
| `Color.brand` | 0x3E9B6C 苔绿 | 主色：进度环/选中态/品牌图形（生长之意） |
| `Color.brandSoft / brandDeep` | 0x7BC49A / 0x2C7A51 | 环形渐变两端 / 今日描边 |
| `Color.flame` | 0xE58B45 | 连击火焰（徽章/统计卡） |
| 习惯八色板 `habitPalette` | 苔绿/蓝/橘/红/紫/青/粉/黄 | 新建习惯轮转取色；格子、行图标、完成率条全部跟随习惯色 |
| `DS.pad / gap / gapSmall` | 16 / 12 / 8 | 页边距 / 卡间距 / 行距（8pt 网格） |
| `DS.radius / radiusSmall` | 16 / 10（continuous） | 卡片 / 内件圆角 |
| `DS.cell / cellGap` | 13 / 3 | 年格子单元（触达下限以上的观感尺寸） |
| 卡片 | fill primary 4.5% + 发丝描边 7% | `.card()` 修饰器，无投影（iOS 原生平视感） |
| 字阶 | 大数字 26pt rounded bold（数字一律 monospacedDigit）/ 行名 headline / 正文 callout / 辅助 caption | |

组件：`SymbolCircle`（习惯色 16% 圆底 + SF Symbol）、`StreakBadge`（火焰胶囊，
0 时灰显）、`ProgressRing`（渐变环 + 环心 x/y）、`StatCard`、`EmptyState`、
`HabitGridView` + `GridCellView`（App/统计共用，自带滚动）。

## 1. 设计原则

1. **今天优先**：打开即「今天」页；进度环是页面唯一大图形。
2. **格子即历史**：GitHub 式格子是品牌记忆点；绿=习惯色，灰=空白，
   语义只有四档（未来/不应做/该没做/完成+进度深浅）。
3. **色随习惯**：全 App 不引入第二套装饰色，每个界面出现的彩色都指向某个习惯。
4. **中文为源语言**，v1 不做英文。
5. **零打断**：唯一的通知是用户主动设置的每日提醒；无角标、无红点、无营销位。

## 2. 页面

### 2.1 今天页（Tab 1 · sun.max）

- 大标题「今天」；工具栏左 EditButton（进入拖拽排序/删除）、右 ＋。
- 头卡：进度环（x/y = 今日已完成/今日应做）+ 日期 + 「还剩 n 件事」；
  全部完成时文案换「全部完成，今天这床布又密了一格」。
- 习惯行：SymbolCircle → 名称 + 副标（节奏/目标；非应做日整行划线）→
  连击徽章 → 打卡控件：
  - 勾选型：circle / checkmark.circle.fill（习惯色）
  - 计数型：`n/goal` 等宽数字 + −（count>0 才出现）/ ＋
- 行点击进详情（NavigationLink value 型，配 `navigationDestination`）。

### 2.2 习惯详情（inline 标题）

- 四张统计卡（2×2）：当前连续（火焰）/ 最长连续（奖杯）/ 30 天完成率 / 累计打卡。
- 「近 30 周」格卡：`HabitGridView` 自带横向滚动，**onAppear 滚到最右**
  （今天=最后一列，brandDeep 描边）；右上角 少→多 图例；脚注创建日期。
- 「最近记录」卡：近 10 条有记录的日期（本地化星期 + ✓/×n）。
- 工具栏 ⋯ 菜单：编辑 / 归档（保留历史）/ 删除（destructive，确认弹窗，删后 dismiss）。

### 2.3 新建/编辑习惯（sheet）

- 「叫什么 · 长什么样」：名称；24 个预设 SF Symbol 六列网格（选中反白）；
  八色板圆点（选中白描边）。
- 「打卡方式」：每日勾选 / 每日计数 segmented；计数时 Stepper 目标（2…99）；
  footer 解释适用场景。
- 「重复」：每天 / 自定义；自定义时周一至周日胶囊（选中反白）；
  footer 点明「不该做的日子不进格子，也不会断链」。
- 「提醒」：Toggle + 时间 DatePicker；首次开启触发权限申请。

### 2.4 统计页（Tab 2 · chart.bar）

- 今日概览卡：环 76pt + 应做/已完成/累计打卡三行 LabeledStat。
- 合并热力卡：近 26 周，颜色=当天应做习惯完成比例（`combinedRatio`）。
- 30 天完成率卡：逐习惯 SymbolCircle + 名称 + 百分比 + 胶囊进度条（习惯色）。

### 2.5 设置（Tab 3 · gearshape）

- 数据：**导出 = ShareLink 表单行**（进页即生成新鲜 JSON，点行直接弹系统分享面板，
  不经过二级 sheet——多 presentation 修饰符叠用会挤掉 sheet 槽位）/ 导入
  （fileImporter，覆盖式，结果 alert）/ 清空全部（confirmationDialog 二次确认）。
- **已归档区**（仅有归档项时出现）：每行图标 + 名称 + 「恢复」「删除」两操作，
  归档习惯的唯一 UI 入口。
- 关于：版本 1.0 (Quilt · 缀)、存储（本机 SwiftData）、网络（零联网）、
  命名出处与对标声明。

### 2.6 无障碍（也是 UI 测试的定位事实源）

- 打卡按钮：`{习惯名}打卡 / {习惯名}取消打卡`；计数行：`{习惯名}加一 / 减一`。
- 工具栏 ＝「新建习惯」；详情菜单「更多操作」；颜色八枚中文名（苔绿/蓝/…）；
  周几胶囊固定中文「周一…周日」（不随系统语言漂移）；24 图标以 SF Symbol
  identifier 为标签。
- List 行内的按钮一律 `.buttonStyle(.borderless)`（否则点击被 NavigationLink 吞掉——
  这既是可玩性 bug 也是可达性 bug）。

### 2.6 小组件

| 小组件 | 尺寸 | 内容 |
|---|---|---|
| 今日习惯 | **小/中/大** | 小：**可编辑锁定单个习惯**（紧凑卡：图标+连击 / 名字+进度 / 大打卡钮），未配置则自动选「该做未完成」——想看多个就加多个小方块；中/大：标题行「今天 x/y」+ 逐习惯行（图标/名/弹性周进度/连击/打卡按钮），最多 3(中)/8(大) 条 |
| 习惯格子 | 中/大 | **长按可换习惯（v2 AppIntentConfiguration）**：头行（图标/名/弹性周进度/连击/打卡钮）+ 26 周格子；未配置时自动选「第一个该做未完成」 |

> 注：iOS 桌面小组件不支持滚动，「一个组件看多个」在中/大尺寸的清单里实现；
> 小尺寸遵循平台惯例 = 单习惯 + 多实例（每个可锁定不同习惯）。

- 打卡按钮 = `ToggleCheckIntent`（App Intent）：勾选型已完成再点=取消今天；
  计数型=+1。写共享 SwiftData → 刷新快照 → reload 时间线。
- 空态：品牌图形 + 「还没有习惯」；`widgetURL = quilt://today` 深链。
- 无障碍：组件内打卡按钮带 `{习惯名}打卡/取消打卡` 显式标签（VoiceOver 可用，
  也是桌面自动化用例 test18 的定位锚点）。

## 3. 连击与弹性语义（视觉一致性的事实源）

- 今天应做但未做：**不断链**（宽限到当日结束），今天格显示空但描边。
- 不应做的日子：格子灰、行划线、不计入链长。
- 创建日之前：格子视为不存在（不显示「欠账」）。
- **弹性习惯（每周 N 次）**：
  - 天天可打（不划线、不显示「今天不用」），但不计入今天页进度环分母；
  - 行内副标「本周 x/N 次 · 弹性」，达标整行副标变品牌色；
  - 连击按**周**折叠：本周未达标不断链（宽限到本周日），统计卡单位切「周」；
  - 格子铺底用全周掩码（天天可着色），30 天完成率按「天天可打」折算。

## 4. 提醒模型（v2 逐日续链）

- 每个习惯任意时刻**至多两条**在排通知：今天（未过点且今天未完成）+ 明天。
- 触发重排：App 回前台、每次打卡（Store.onSave 钩子）、编辑保存。
- 效果：当天已完成 → 今天的提醒不再出现；代价是连续多天不打开 App 时
  提醒链会断（打开即续），个人工具可接受。
- identifier 约定：`habit-{uuid}-0 / -1`，重排前先成对移除。
